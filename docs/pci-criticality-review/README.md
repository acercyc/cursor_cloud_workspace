# Literature review: does PCI index proximity to brain criticality?

Personal (non-publication) review executed from the Notion agent plan *AI Agent Plan: Literature Review — Brain Near-Criticality & Perturbational Complexity (PCI)*.

**Guiding question.** To what extent do perturbational complexity measures (PCI, PCIst, related signal-diversity measures) index proximity to criticality in cortical dynamics — and is this relationship necessary, contingent, or coincidental for consciousness?

**Short answer.** **Partly.** PCI is a strong *empirical correlate* of proximity to *some* critical regimes in healthy pharmacological models, and theory predicts that perturbational complexity peaks near criticality. It is **not** a pure operational measure of “distance from criticality,” because (i) criticality is not one thing, (ii) PCI saturates at waking capacity while spontaneous diversity can still rise (psychedelics, sub-anaesthetic ketamine), and (iii) the mechanistic bottleneck that actually drops PCI is often **cortical bistability / OFF-periods**, which can be *reinterpreted* as a departure from an asynchronous near-critical regime but is not identical to it. The relationship looks **contingent** (shared computational geometry: integration + differentiation) rather than **necessary identity**.
