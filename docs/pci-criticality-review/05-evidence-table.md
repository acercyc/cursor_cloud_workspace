**Pattern in one sentence.** Whenever *the same brains* provide both a near-criticality assay and PCI, they move together through **wake / ketamine vs propofol / xenon**. Whenever complexity is **spontaneous** (psychedelics, sub-anaesthetic ketamine), it can leave PCI behind. Whenever the assay is **bistability**, it explains PCI without needing power laws.
